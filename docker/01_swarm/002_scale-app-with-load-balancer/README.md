# Масштабирование приложения с балансировщиком нагрузки

## Задача

Настроить Docker-окружение, в котором приложение запускается в **5 экземплярах (replicas)**, а контейнер **Nginx** работает как **балансировщик нагрузки**, равномерно распределяя входящий HTTP-трафик между всеми экземплярами приложения.

## Требования

- В `docker-compose.yml` должны быть описаны:
  - сервис **Nginx** как входная точка (`80:80`)
  - сервис **app**, работающий в **5 репликах**
  - общая сеть Docker для внутреннего взаимодействия сервисов
- Nginx должен проксировать запросы на сервис приложения и балансировать трафик между репликами.

## Ожидаемый результат

- Запросы на `http://localhost` принимает Nginx
- Nginx перенаправляет их на экземпляры приложения
- Трафик распределяется между всеми 5 репликами (балансировка работает)

## Файлы

- `docker-compose.yml` — описание сервисов Nginx и приложения + параметры масштабирования
- `nginx.conf` — конфигурация upstream в Nginx для балансировки нагрузки
